# موقع مقاول حفر وترحيل ودفان

موقع عربي متجاوب جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` الصفحة الرئيسية
- `services.html` صفحة الخدمات
- `products.html` صفحة المنتجات والمعدات
- `style.css` التصميم

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع الملفات كما هي.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر Branch: `main` والمجلد `/ (root)` ثم Save.
5. بعد ظهور الرابط، استخدمه كموقع إلكتروني في ملفك التجاري على Google.

## Google
أضف رابط الموقع إلى ملف Google Business Profile بعد نشره. ولظهور النشاط في بحث Google وخرائط Google، أنشئ/طالب بملف النشاط التجاري وأكمل التحقق الذي تطلبه Google.
